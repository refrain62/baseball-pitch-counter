# PC-001: 投手ごとのイニング別球数と交代後の訂正

状態: 実装PRレビュー待ち

## 要件

1. 試合のイニングを切り替え、各チーム側・各投手の球数をイニング別に記録する。
2. イニングを切り替えても投手の累計球数を維持する。
3. 投手交代後も交代済み投手の各イニング球数と累計を訂正できる。
4. 現在の投手の記録も確認・訂正でき、合計表示と回別表示を同期する。
5. 既存の `pitch-counter-state-v3` 保存データを維持する。回別情報がない旧累計はイニング未設定分として残し、1回などに誤って割り当てない。

## 操作とデータの扱い

- 画面上部の「−／＋」で両側に共通する現在のイニングを1〜99回の範囲で切り替える。
- 球を追加・戻す操作は、選択中のイニングの球数を更新し、投手の累計へ反映する。
- 投手交代では、現在の投手記録を履歴へ移し、新しい投手を0球から記録する。
- 現在投手の回別表示、または交代済み投手の履歴を開くと、イニング別と未設定分の球数を訂正できる。
- 投手1人あたりの累計は999球まで、各側の投手記録は現役を含め100人までとする。
- データは既存どおりブラウザーの `localStorage` に保存し、サーバーには送信しない。

## 完了条件

- 現在投手・交代済み投手の記録で、累計が回別球数と未設定分の和に一致する。
- 過去のイニングへ戻って訂正しても、後続イニングの記録が失われない。
- 旧形式の保存データを読み込んだとき、旧累計を保持しながら回別情報を捏造しない。
- `pnpm test` と `pnpm build` が成功する。
